Ground Truth

CSV 与图像的关系

专家并不是给每层画 mask，而是给每个结节一行 3D 标注

  • 一例 CT 对应一个 seriesuid，文件名与 .mhd/.raw 一致。
  • coordX/Y/Z 是结节中心的世界坐标，单位为 mm。
  • diameter_mm 给出结节直径，用于判断候选是否落入半径范围。
  • 程序输出的是体素坐标，需要用 .mhd 中的 Offset 与 ElementSpacing 转换。
验证不是肉眼看红圈，而是：程序候选中心 → 世界坐标 → 与官方中心计算 3D 距离。distance ≤ diameter/2 视为严格命中

逐层 2D 检测

候选怎么找出来

每一层切片上，候选来自“肺内 + 增强亮斑 + 软组织 HU”

1. 限定搜索范围

  • 使用 HU < -320 初步找到肺内低密度区域
  • 去除与图像边界连通的体外空气
  • 保留最大两个连通域，近似左右肺

2. 频域带通增强

  • 对肺内区域做 FFT
  • 使用 σlow=30, σhigh=5 的高斯差带通
  • 压制大背景和细噪声，保留中等尺度结构

3. 生成种子区域

  • 取肺区域增强值第 85 百分位作为亮斑阈值
  • 要求 -500 < HU < 250，排除空气和极高密度结构
  • 闭运算连接临近亮点

4. 连通域变候选

  • 每个白色连通块视为一个 2D 候选
  • 计算面积、中心、直径、圆形度、HU 均值与纹理
  • 再由相邻层空间接近的候选合并为 3D 候选

候选保留策略

Top-K trade-off

如果要更少红圈，可以切换工作点；当前选择召回优先

为什么最终选 K=180？

  • K=120 时测试集 FP/例更低，但严格召回为 24/40。
  • K=180 时测试集严格召回保持 25/40，与 baseline 一致。
  • 课堂汇报优先证明“能检出”，所以当前版本保留召回优先设置。
  • 现场演示若想更清爽，可以临时展示 Top120/Top150 工作点。

局限与改进

Why not perfect?

传统算法可解释，但血管与边缘仍是主要假阳性来源

当前局限

  • 血管横截面与小结节在单层上很像
  • 靠圆形度和 HU 很难完全区分血管交叉
  • MIP 显示仍偏粗糙，适合概览但不适合诊断

验证层面

  • LUNA16 标注是 3D 中心点和直径，不是逐像素 mask
  • 严格半径匹配对中心偏移比较敏感
  • 真实医学 CAD 还需要 FROC 等更完整指标

下一步优化

  • 加入长宽比、偏心率、二阶矩等形状特征
  • 增加 Hessian/Frangi 类血管抑制响应
  • 改进 3D 连通聚类，减少孤立切片误报

课程价值

  • 覆盖采样量化、灰度变换、频域增强
  • 覆盖形态学、图像分割、连通域分析
  • 覆盖特征描述、可视化与定量验证
